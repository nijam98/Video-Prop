    🔒 Token disimpan dalam browser peranti ini sahaja dan hanya dihantar terus ke Facebook/Threads. Jangan simpan token di telefon atau komputer orang lain.
    📘 Cara dapat token

    Facebook Page

    1. developers.facebook.com → Create App → use case Manage everything on your Page.
    2. Graph API Explorer → pilih app → Get User Access Token dengan permission pages_show_list, pages_read_engagement, pages_manage_posts, pages_manage_engagement. Pilih Page anda dalam popup.
    3. Access Token Debugger → tampal token → Extend Access Token.
    4. Kembali ke Explorer dengan token panjang → me/accounts?fields=id,name,access_token → Submit. Salin id (Page ID) dan access_token.

    Threads

    1. Dalam app yang sama: Add use case → Access the Threads API. Aktifkan threads_basic dan threads_content_publish.
    2. App roles → Roles → tambah username Threads anda sebagai Threads Tester. Dalam app Threads: Settings → Account → Website permissions → Invites → Accept.
    3. Guna User Token Generator dalam tetapan use case Threads untuk dapatkan token.
