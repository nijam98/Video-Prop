# Panduan Gaya Post Threads

**Siapa:** Agent hartanah, kawasan Utara (Pulau Pinang, Kedah, Perlis, Perak utara).
**Sasaran:** Pembeli rumah pertama, keluarga muda, pekerja kilang / zon industri, pelabur kecil.

## Peraturan
1. Bahasa Melayu santai (gaya "aku / kau / korang"), boleh campur sikit English.
2. **Baris pertama = hook padu** — soalan pedih, kenyataan mengejut, atau janji jelas. Maks ~12 patah perkataan.
3. Maks **450 aksara** (had Threads 500). Baris pendek, banyak ruang putih.
4. Satu idea satu post. Tiada hashtag berlebihan (0–1 sahaja).
5. Akhiri dengan CTA lembut: soalan untuk komen, atau "DM aku SEMAK".
6. **Jangan reka** nombor, kadar faedah, harga, statistik atau cerita client. Kalau tak pasti fakta, cakap secara umum.
7. Jangan janji loan lulus atau untung pelaburan.
8. Ikut slot waktu:
   - 08:00 Edukasi / loan
   - 12:00 Silap pembeli / tips
   - 15:00 Kawasan Utara / behind the scenes
   - 18:00 Debat / soalan engagement
   - 21:00 Soft sell / CTA
   Kalau idea seterusnya tak kena slot, ambil idea `[ ]` lain yang paling sesuai.
