# Kedai Saya — Website Jualan

Website satu halaman yang membawa pelanggan ke **Shopee** (untuk beli) dan **TikTok** (untuk tonton video).

## Cara tukar maklumat kedai

Buka `index.html`, cari bahagian **"TUKAR MAKLUMAT KEDAI ANDA DI SINI"** (di bahagian bawah fail), dan ubah:

- `nama` — nama kedai
- `shopee` — link kedai Shopee anda, contoh `https://shopee.com.my/kedaiabc`
- `tiktok` — link TikTok anda, contoh `https://www.tiktok.com/@kedaiabc`
- `produk` — senarai barang. Untuk setiap produk:
  - `shopee` — link produk di Shopee (kosong = guna link kedai)
  - `tiktok` — link video produk di TikTok (kosong = guna link akaun)
  - `gambar` — link gambar produk (kosong = guna emoji)

## Cara online-kan (percuma) dengan GitHub Pages

1. Di GitHub, buka repo ini → **Settings** → **Pages**
2. Di "Branch", pilih `main` dan folder `/ (root)` → **Save**
3. Tunggu 1–2 minit. Website akan ada di `https://nijam98.github.io/video-prop/`
